# Python SCPI Electronic Load Controller

**Status:** Planned (Milestone 5)

Translates web hemodynamic parameters (`Pump Speed 4,800–6,200 RPM`, `Flow`, `PI`, `Artificial Pulse`) into real-time SCPI current/wattage commands for a programmable DC electronic load (`Korad KEL103` / `Rigol DL3021` / `Siglent SDL1020X`).
