# Hardware Designs & Bill of Materials

**Status:** Planned (Milestone 4)

All prototype hardware standardizes on general-purpose connectors (**XT60**, **4-pin JST-GH / Grove I²C**, **UART**, **USB-C PD**).

* `carrier-pcb/` — KiCad schematics, PCB layouts, and Gerber releases.
* `ideal-diode-combiner/` — `LM5050` / `LTC4412` / `LM74700-Q1` dual-pack OR-ing isolation board.
* `BOM.csv` — High-level component Bill of Materials (personal purchase receipts and Square R&D donation accounting are maintained privately).
